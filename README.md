# Атомные привычки — трекер привычек для Android

Нативное Android-приложение (Kotlin + Jetpack Compose) для ежедневного
трекинга привычек, вдохновлённое форматом [Tick It — Habit Tracker](https://play.google.com/store/apps/details?id=habittracker.todolist.tickit.daily.planner)
и книгой Джеймса Клира «Атомные привычки».

## Возможности

1. **Ежедневный трекинг** — список привычек на сегодня с отметкой в один тап,
   привычки настраиваются на конкретные дни недели.
2. **Уведомления** — персональное время напоминания на каждую привычку,
   с быстрой кнопкой «Готово ✓» прямо в уведомлении.
3. **Google Таблица как хранилище** — не просто экспорт, а полноценный бэкап:
   привычки и вся история отметок сохраняются в вашу личную таблицу (через
   Apps Script, без сложного OAuth), и после удаления/переустановки
   приложения кнопка **«Восстановить из Google Таблиц»** возвращает всё обратно.
4. **Графики по каждой привычке** — текущая и лучшая серия (streak), % выполнения,
   календарь-«тепловая карта» и столбчатый график за 30 дней.
5. **4 закона Джеймса Клира** — при создании привычки можно сразу заполнить
   все 4 закона атомных привычек:
   1. Сделай очевидной (где и когда)
   2. Сделай привлекательной (habit stacking / temptation bundling)
   3. Сделай лёгкой (правило двух минут)
   4. Сделай приятной (мгновенная награда)
6. **Обновление прямо из приложения** — кнопка «Проверить обновления» в
   настройках сама находит последнюю сборку в GitHub Releases этого
   репозитория, скачивает и запускает установку — заходить на GitHub вручную
   не нужно.

## ⚠️ Важно: как собрать APK

Этот репозиторий содержит **исходный код**, а не готовый `.apk`-файл — GitHub
не хранит бинарные сборки в исходниках. Собрать реальный `.apk` можно двумя
способами (оба описаны подробно в [`docs/SETUP_ANDROID_STUDIO.md`](docs/SETUP_ANDROID_STUDIO.md)):

- **Автоматически в облаке** — репозиторий уже содержит GitHub Actions
  (`.github/workflows/build.yml`), который сам соберёт debug-APK при каждом
  push и выложит его как Artifact — Android Studio для этого не нужна.
- **Локально в Android Studio** — `Build → Build APK(s)`, обычный процесс.

## Структура проекта

```
app/src/main/java/com/atomichabits/tracker/
├── data/            Room-сущности (Habit, HabitLog), DAO, репозиторий, DataStore-настройки
├── notifications/   Планировщик напоминаний (AlarmManager), BroadcastReceiver'ы
├── sheets/          Экспорт/восстановление через Google Sheets (OkHttp → Apps Script) + WorkManager-синк
├── update/          Проверка и установка обновлений из GitHub Releases
├── ui/
│   ├── home/        Главный экран — привычки на сегодня
│   ├── addedit/      Создание/редактирование привычки + 4 закона Клира
│   ├── detail/       Статистика, тепловая карта, график
│   ├── settings/     Настройка Google Sheets, уведомления
│   ├── components/   Переиспользуемые UI-компоненты
│   └── theme/        Material 3 тема
apps-script/
└── HabitSheetSync.gs Google Apps Script — принимает данные и пишет в таблицу
docs/
├── SETUP_ANDROID_STUDIO.md   Сборка APK (Android Studio и GitHub Actions)
└── SETUP_GOOGLE_SHEETS.md    Настройка Google-таблицы и Apps Script (10 минут)
```

## Технологии

- **Kotlin** + **Jetpack Compose** (Material 3) — весь UI
- **Room** — локальная база данных (привычки и история выполнения)
- **WorkManager** — фоновая синхронизация с Google Sheets
- **AlarmManager** — точные ежедневные напоминания, переживающие перезагрузку
- **DataStore** — хранение настроек (URL таблицы, автосинхронизация)
- **Compose Canvas** — 30-дневный график рисуется напрямую, без сторонней
  библиотеки графиков (чтобы не зависеть от чужого API, который может
  измениться между версиями)
- **OkHttp** — отправка данных в Apps Script
- Минимум **Android 8.0 (API 26)**, целевой **Android 15 (API 35)**

## Быстрый старт

1. Прочитайте [`docs/SETUP_GOOGLE_SHEETS.md`](docs/SETUP_GOOGLE_SHEETS.md) и
   разверните свой Apps Script (10 минут, один раз).
2. Прочитайте [`docs/SETUP_ANDROID_STUDIO.md`](docs/SETUP_ANDROID_STUDIO.md) и
   соберите `.apk` любым из двух способов.
3. Установите APK на телефон, вставьте URL Apps Script в настройках приложения.
4. Создайте первую привычку — заполните 4 закона, если хотите.

## Публикация на GitHub

Локально в этой папке уже инициализирован git-репозиторий с первым коммитом.
Чтобы выложить его на свой GitHub:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/atomic-habits-tracker.git
git branch -M main
git push -u origin main
```

(Создайте пустой репозиторий на github.com заранее, без README/gitignore —
они уже есть здесь, чтобы избежать конфликтов при первом push.)

## Известные ограничения / что можно улучшить дальше

- Debug-сборка не подписана релизным ключом — этого достаточно для личной
  установки, но не для публикации в Play Store.
- **Первый раз после появления кнопки «Проверить обновления»** её ещё нет в
  уже установленной версии — этот самый APK нужно поставить вручную (как
  раньше, через Artifacts или релиз в Actions) один последний раз. Все
  версии после этого уже можно ставить прямо из приложения.
- Восстановление из Google Таблиц не удаляет локальные данные, только
  добавляет/обновляет по совпадению — если нужно «начать с чистого листа»
  из таблицы, пока проще удалить и заново установить приложение перед
  восстановлением.
- Поддерживается только один Google-аккаунт/таблица одновременно — этого
  достаточно для личного трекера, каким и задумывалось приложение.
