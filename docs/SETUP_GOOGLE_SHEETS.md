# Настройка экспорта в Google Таблицы

Экспорт работает через **Google Apps Script**, а не через официальный Sheets API с OAuth.
Это проще для личного использования: не нужно заводить проект в Google Cloud Console,
включать API и проходить верификацию — весь скрипт работает под вашим собственным
Google-аккаунтом, привязанным напрямую к вашей таблице.

Всё занимает ~10 минут и делается один раз.

## Шаг 1. Создайте Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → **Пустая таблица**.
2. Назовите её, например, «Атомные привычки — статистика».
3. Ничего больше настраивать не нужно — лист «Habits» с заголовками скрипт создаст сам.

## Шаг 2. Откройте редактор Apps Script

1. В таблице: **Расширения → Apps Script**.
2. Откроется отдельная вкладка с редактором кода, уже привязанным к этой таблице.
3. Удалите весь код-заглушку (`function myFunction() {...}`), который там по умолчанию.

## Шаг 3. Вставьте код скрипта

1. Откройте файл [`apps-script/HabitSheetSync.gs`](../apps-script/HabitSheetSync.gs) из этого репозитория.
2. Скопируйте всё содержимое и вставьте в редактор Apps Script.
3. Нажмите значок дискеты (Сохранить проект). Можно дать проекту имя, например «HabitSheetSync».

## Шаг 4. Разверните как веб-приложение

1. Справа сверху нажмите **Развернуть → Новое развертывание** (Deploy → New deployment).
2. Слева от шестерёнки выберите тип **Веб-приложение** (Web app).
3. Заполните:
   - **Executing as (Выполнять как):** `Me (ваш email)`
   - **Who has access (У кого есть доступ):** `Anyone` (Все)

   > Это не значит, что таблица становится публичной — доступ к самой таблице не меняется.
   > Это лишь позволяет приложению на телефоне слать данные на URL скрипта без входа в Google-аккаунт.
   > URL длинный и непубличный — храните его так же, как обычный пароль/токен.
4. Нажмите **Развернуть** (Deploy).
5. Google попросит авторизовать скрипт (Review permissions → выберите свой аккаунт →
   «Advanced» → «Go to HabitSheetSync (unsafe)» → Allow). Это стандартное предупреждение
   для любого несертифицированного личного скрипта — сами себе вы можете доверять.
6. После развёртывания вы получите **Web app URL** вида:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   Скопируйте его полностью.

## Шаг 5. Вставьте URL в приложение

1. Откройте приложение «Атомные привычки» → значок настроек (⚙️) на главном экране.
2. Вставьте скопированный URL в поле **«URL веб-приложения Apps Script»**.
3. Нажмите **«Экспортировать сейчас»** — должно появиться «Экспортировано успешно».
4. Проверьте таблицу: должен появиться лист **Habits** с шапкой `Date | Habit | Completed | Synced At`.
5. Включите тумблер **«Автосинхронизация»**, чтобы приложение само отправляло новые
   отметки о выполнении привычек (сразу после отметки + раз в 6 часов в фоне).

## Обновление скрипта в будущем

Если вы отредактируете `HabitSheetSync.gs` (например, добавите свою логику), нужно
создать **новое развёртывание** (Deploy → Manage deployments → Edit → New version),
иначе изменения не применятся к уже выданному URL.

## Диагностика

- **«Ошибка экспорта»** в приложении → откройте Web app URL прямо в браузере телефона/компьютера:
  должно вернуться `{"ok":true,"message":"HabitSheetSync is running..."}`. Если вместо
  этого просит войти в аккаунт — доступ выставлен не на «Anyone», вернитесь к шагу 4.
- **Строки не появляются** → проверьте, что копировали `.gs`-файл целиком, без обрезки,
  и что после правок сделали новое развёртывание (см. выше).
- Каждая привычка сохраняется в таблице отдельной строкой на каждый день, когда она была
  отмечена выполненной — так удобнее всего строить сводные таблицы/графики средствами
  самого Google Sheets (например, через `QUERY` или сводные таблицы).
