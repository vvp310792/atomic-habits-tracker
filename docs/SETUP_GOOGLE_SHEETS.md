# Настройка Google Таблиц как хранилища

Google Таблица работает как **полноценное хранилище** для приложения: в ней
сохраняются и сами привычки (название, иконка, дни, напоминание, 4 закона),
и вся история отметок. Благодаря этому, если вы удалите приложение и
установите заново, можно вернуть всё обратно кнопкой «Восстановить».

Работает это через **Google Apps Script**, а не через официальный Sheets API
с OAuth — не нужно заводить проект в Google Cloud Console, включать API и
проходить верификацию. Скрипт разворачивается под вашим личным Google-аккаунтом
и обращается только к вашей собственной таблице.

Всё занимает ~10 минут и делается один раз.

> **Уже настраивали таблицу раньше (старая версия с одним листом «Habits»)?**
> Перейдите сразу к разделу [«Обновление уже настроенного скрипта»](#обновление-уже-настроенного-скрипта) —
> нужно просто заменить код скрипта, создавать всё заново не придётся.

## Шаг 1. Создайте Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → **Пустая таблица**.
2. Назовите её, например, «Атомные привычки — база данных».
3. Ничего больше настраивать не нужно — нужные листы скрипт создаст сам.

## Шаг 2. Откройте редактор Apps Script

1. В таблице: **Расширения → Apps Script**.
2. Откроется отдельная вкладка с редактором кода, уже привязанным к этой таблице.
3. Удалите весь код-заглушку (`function myFunction() {...}`), который там по умолчанию.

## Шаг 3. Вставьте код скрипта

1. Откройте файл [`apps-script/HabitSheetSync.gs`](../apps-script/HabitSheetSync.gs) из этого репозитория.
2. Скопируйте всё содержимое и вставьте в редактор Apps Script.
3. Нажмите значок дискеты (Сохранить проект). Можно дать проекту имя, например «HabitSheetSync».

## Шаг 4. Разверните как веб-приложение

1. Справа сверху нажмите **Развернуть → Новое развертывание** (Deploy → New deployment).
2. Слева от шестерёнки выберите тип **Веб-приложение** (Web app).
3. Заполните:
   - **Executing as (Выполнять как):** `Me (ваш email)`
   - **Who has access (У кого есть доступ):** `Anyone` (Все)

   > Это не значит, что таблица становится публичной — доступ к самой таблице не меняется.
   > Это лишь позволяет приложению на телефоне слать данные на URL скрипта без входа в Google-аккаунт.
   > URL длинный и непубличный — храните его так же, как обычный пароль/токен.
4. Нажмите **Развернуть** (Deploy).
5. Google попросит авторизовать скрипт (Review permissions → выберите свой аккаунт →
   «Advanced» → «Go to HabitSheetSync (unsafe)» → Allow). Это стандартное предупреждение
   для любого несертифицированного личного скрипта — сами себе вы можете доверять.
6. После развёртывания вы получите **Web app URL** вида:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```
   Скопируйте его полностью.

## Шаг 5. Вставьте URL в приложение

1. Откройте приложение «Атомные привычки» → значок настроек (⚙️) на главном экране.
2. Вставьте скопированный URL в поле **«URL веб-приложения Apps Script»**.
3. Нажмите **«Экспортировать сейчас»** — должно появиться «Экспортировано успешно».
4. Проверьте таблицу: должны появиться листы **HabitDefinitions** (сами привычки)
   и **HabitLogs** (отметки о выполнении).
5. Включите тумблер **«Автосинхронизация»**, чтобы приложение само отправляло
   изменения (новую/изменённую привычку, отметки о выполнении) сразу и раз в
   6 часов в фоне.

## Восстановление после переустановки

Если вы удалите и заново установите приложение (или поставите его на новый
телефон):

1. Установите APK как обычно.
2. Настройки (⚙️) → вставьте **тот же самый** URL Apps Script.
3. Нажмите **«Восстановить из Google Таблиц»** → подтвердите.
4. Приложение подтянет все привычки и историю обратно, включая настроенные
   напоминания.

Сопоставление происходит по внутреннему идентификатору каждой привычки
(не по названию), поэтому даже если вы переименуете привычку, история не потеряется.

## Обновление уже настроенного скрипта

Если вы уже разворачивали более раннюю версию скрипта (с одним листом
«Habits»), обновиться просто — старый URL продолжит работать:

1. Откройте вашу таблицу → **Расширения → Apps Script**.
2. Выделите весь старый код и удалите его.
3. Вставьте новое содержимое [`apps-script/HabitSheetSync.gs`](../apps-script/HabitSheetSync.gs) целиком.
4. Сохраните (значок дискеты).
5. **Развернуть → Управление развёртываниями** (Deploy → Manage deployments) →
   значок карандаша (Edit) у существующего развёртывания → в поле «Version»
   выберите **New version** → **Развернуть** (Deploy).
6. URL остаётся тем же — в приложении менять ничего не нужно.
7. Старый лист «Habits» с прежними данными останется в таблице нетронутым —
   можно оставить как есть или удалить вручную, он больше не используется.

## Диагностика

- **Ошибка экспорта/восстановления** → откройте Web app URL прямо в браузере
  телефона/компьютера: должно вернуться что-то вроде
  `{"ok":true,"habits":[...],"logs":[...]}`. Если вместо этого просит войти в
  аккаунт — доступ выставлен не на «Anyone», вернитесь к шагу 4.
- **После правок скрипта ничего не изменилось** → не забыли создать **новое
  развёртывание** (см. выше)? Без этого шага правки не применяются к уже
  выданному URL.
- **«В таблице пока ничего нет» при восстановлении** → на этом Google-аккаунте
  ещё не было ни одной синхронизации (или URL указывает на другую таблицу).
