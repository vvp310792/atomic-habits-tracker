# Сборка APK в Android Studio

## Вариант А — без установки чего-либо (проще всего)

Репозиторий уже содержит workflow **GitHub Actions** (`.github/workflows/build.yml`),
который сам собирает debug-APK в облаке при каждом push в ветку `main`.

1. Запушьте репозиторий на свой GitHub (см. главный [README](../README.md#публикация-на-github)).
2. Откройте вкладку **Actions** в репозитории на GitHub.
3. Дождитесь, пока workflow **Build APK** пройдёт (обычно 2–4 минуты).
4. Откройте завершённый запуск → внизу раздел **Artifacts** → скачайте
   `atomic-habits-debug-apk.zip`, распакуйте — внутри `app-debug.apk`.
5. Скопируйте apk на телефон и установите (см. «Установка APK на телефон» ниже).

Повторять для каждого обновления кода не нужно вручную — Actions запускается
автоматически при каждом push.

## Вариант Б — через Android Studio

### 1. Установите Android Studio

Скачайте с [developer.android.com/studio](https://developer.android.com/studio),
установите, при первом запуске дайте мастеру настройки скачать Android SDK
(платформа API 35, build-tools) — это займёт несколько минут.

### 2. Откройте проект

`File → Open` → выберите папку `habit-tracker-atomic` (корень репозитория,
там где лежит `settings.gradle.kts`).

Android Studio сама запустит **Gradle Sync** (индикатор внизу справа) —
дождитесь, пока он завершится (первый раз — несколько минут, скачиваются
зависимости).

### 3. Соберите APK

`Build → Build App Bundle(s) / APK(s) → Build APK(s)`.

По завершении в правом нижнем углу появится уведомление
«APK(s) generated successfully» → нажмите **locate** — откроется папка с файлом:

```
app/build/outputs/apk/debug/app-debug.apk
```

### 4. Установите APK на телефон

Самый простой способ — через USB и ADB:

1. На телефоне: **Настройки → О телефоне** → 7 раз нажать «Номер сборки» →
   включится «Для разработчиков».
2. **Настройки → Для разработчиков** → включите «Отладка по USB».
3. Подключите телефон к компьютеру, разрешите отладку на экране телефона.
4. В Android Studio: `View → Tool Windows → Terminal`, выполните:
   ```
   adb install app/build/outputs/apk/debug/app-debug.apk
   ```

Либо просто скопируйте `app-debug.apk` на телефон (по кабелю, через облако,
телеграм самому себе и т.д.) и откройте файл — Android спросит разрешение
«Установить из неизвестных источников» для вашего файлового менеджера, один раз.

### Возможные проблемы при первой синхронизации

- **«SDK location not found»** — Android Studio сама предложит скачать
  недостающие компоненты SDK (compileSdk 35, build-tools) — соглашайтесь.
- **Ошибка версии Gradle/AGP** — используйте Android Studio версии Ladybug
  (2024.2) или новее; она уже совместима с Gradle 8.9 / AGP 8.7, указанными
  в проекте.
- **Отсутствует `gradle-wrapper.jar`** — в репозитории он уже есть (это
  небольшой бинарный файл), но если Git его не подтянул (например, при
  ручном копировании файлов без `.git`), выполните `gradle wrapper` при
  установленном локально Gradle, либо просто откройте проект в Android
  Studio — она способна восстановить wrapper через
  `File → Sync Project with Gradle Files`.

### Release-сборка (не обязательно)

Для собственного использования достаточно debug-APK. Если захотите
release-сборку (для публикации в Play Store или меньшего размера файла),
понадобится создать подписывающий ключ (`Build → Generate Signed Bundle / APK`) —
это отдельная тема, спросите отдельно, если понадобится.
