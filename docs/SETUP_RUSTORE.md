# Публикация в RuStore

## Что уже готово (сделано технически)

- **Релизная подпись** — сгенерирован отдельный release-keystore (не тот же,
  что debug), хранится безопасно как зашифрованный GitHub Secret, в код и
  репозиторий не попадает.
- **Сборка релизного APK** — при каждом push в `main` CI теперь дополнительно
  собирает подписанный release-APK (с минификацией R8) и кладёт его как
  Artifact в GitHub Actions — скачивается со страницы конкретного запуска
  (Actions → нужный запуск → раздел Artifacts внизу → `atomic-habits-release-apk`).
- **Иконка для карточки в сторе** — `store/rustore/icon-512.png` (512×512,
  в цветах приложения — та же молния, что в самом приложении и на нижней
  панели навигации).
- **Политика конфиденциальности** — опубликована через GitHub Pages:
  **https://vvp310792.github.io/atomic-habits-tracker/privacy-policy.html**
  (появится по ссылке через пару минут после ближайшего push — GitHub Pages
  собирается не мгновенно).
- **Автообновление через GitHub Releases сохранено без изменений** — как вы
  и просили, релизная сборка для RuStore существует отдельно, ничего в
  текущей debug-сборке не меняется.

## Что делаете вы

### 1. Регистрация в RuStore Консоль
- Откройте [consolerustore.ru](https://consolerustore.ru)
- Войдите через VK ID
- Тип аккаунта — **физическое лицо**
- Пройдите верификацию личности (паспортные данные)
- Примите оферту разработчика

### 2. Создайте приложение в консоли
- **Package name**: `com.atomichabits.tracker`
- **Категория**: Здоровье и фитнес (или Продуктивность — на ваше усмотрение)
- **Возрастной рейтинг**: заполняется через анкету в самой консоли
- **Иконка**: загрузите `store/rustore/icon-512.png` из репозитория
- **Описание** — на русском (обязательно с 1 марта 2026), например:
  > Трекер привычек по методу «Атомных привычек» Джеймса Клира — 4 закона
  > формирования привычек, привычка-стек, библиотека полезных и вредных
  > привычек, модуль «Позыв» для перехвата импульсивных срывов, синхронизация
  > между устройствами.
- **Политика конфиденциальности**: вставьте ссылку выше

### 3. Загрузите APK
Скачайте `atomic-habits-release-apk` из Artifacts последнего успешного
запуска в GitHub Actions (см. выше) и загрузите его в RuStore Консоль.

### 4. Отправьте на модерацию
После заполнения всех полей — кнопка отправки на проверку. Модерация обычно
занимает несколько дней.

## Важно про версии

APK для RuStore и APK для GitHub Releases — теперь два независимых, но
синхронизированных по номеру версии артефакта одной и той же сборки: у обоих
`versionCode` берётся из номера запуска CI, так что можно всегда сопоставить,
какая версия где. Обновлять версию в RuStore нужно будет вручную — через
загрузку нового APK в консоли при каждом релизе (RuStore не умеет сам
подтягивать с GitHub).

## Диагностика

- **Не приходит подтверждение регистрации разработчика** — проверьте, что
  паспортные данные введены точно как в документе, при ошибках RuStore
  обычно присылает уточнение на почту, привязанную к VK ID.
- **Модерация отклонила по описанию/материалам** — почти всегда причина в
  тексте не на русском языке или отсутствии политики конфиденциальности —
  проверьте оба пункта выше.
